# Bandstand 0.1.0, public beta

Bandstand is a sheet music reader and gig book for working musicians, and you run
it yourself. Put your charts on a computer you own, read them on a tablet on
stage, and share the book with your band. No account with anybody, no
subscription, nothing stored on somebody else's computer.

This is the first public release. It is a beta: it has been played on real gigs
and rehearsals for months, by one band leader and the bands around him, and now
it is ready for more people to try. Expect rough edges, and please tell us about
them.

## What you get

- **Reading:** PDF charts with fast page turns (tap, swipe, keyboard or a
  Bluetooth pedal), half-page turns, two pages side by side, pinch to zoom, and a
  dark stage mode.
- **Marking up:** pen, highlighter and typed labels that appear on every device.
- **Setlists:** build a set with breaks and play straight through it.
- **Practice:** loop the hard bar of a recording and slow it down without
  changing the pitch.
- **Your band:** each player gets their own sign-in link. Members can read
  everything and keep private notes; only you can change the library.
- **Offline:** on a secure address, save a setlist to the tablet before a gig
  with no signal.
- **Rehearsal rooms (off until you switch them on):** a QR code on the wall,
  everyone suggests songs and votes from their phone, you call the next tune.

## Try it

You need a computer that can stay on (an old laptop, a Mac mini, a 64-bit
Raspberry Pi) with Docker installed. Then:

```
git clone https://github.com/gloryjams/bandstand.git bandstand
cd bandstand
docker compose up -d
```

Open `http://localhost:7800/app/` and follow the
[self-hosting guide](https://github.com/gloryjams/bandstand/blob/main/docs/SELF-HOSTING.md)
from Step 5. It takes about 20 minutes, most of it downloads.

The image is `ghcr.io/gloryjams/bandstand:0.1.0`, for ordinary PCs and for Arm
computers such as Apple Silicon Macs and the Raspberry Pi.

## Good to know before you rely on it

- **Security.** Bandstand is a public beta. Run it on your home network or behind Tailscale or WireGuard. If you put it on the internet, use https (a reverse proxy) and set `BANDSTAND_LIBRARY_QUOTA_MB`. Anyone who can watch your network traffic on plain http can read the director key. Only add bands, open sign-in links and import band copies from people you trust. Rehearsal rooms let anyone holding the room QR code post to your server while the room is open: close the room when rehearsal ends.
- iPhone and iPad support is new in this release and has been tested in code,
  not yet on many real devices. If something looks wrong on yours, please report
  it with the device and its software version.
- Charts are kept on the tablet for offline use only on a secure (`https://`)
  address. The guide explains the options.
- The SaltyCharts chord chart editor is not available for download yet.
  Bandstand works without it.
- The live jam board for open jam sessions is being built and is not part of
  this release.
