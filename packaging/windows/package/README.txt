BANDSTAND
A sheet music reader, gig book, and chord chart editor.

START ON WINDOWS
1. Right-click the downloaded ZIP and choose Extract All.
2. Open the extracted Bandstand folder and double-click Start Bandstand.
3. Your browser opens. Confirm the sign-in, then try the four practice charts
   or create a chart with the included SaltyCharts editor.

You do not need to install Python, Node, or Docker. This build is for 64-bit
Windows 10 or 11. It is an unsigned public beta.

YOUR BOOK
Your charts, sign-in key, database, and daily backups are saved in:
  %LOCALAPPDATA%\Bandstand
Paste that address into File Explorer to find the folder. Add PDFs through
the app's Library, or drop them in its library folder while Bandstand runs.
The four practice charts are original exercises, not a song collection.

UPDATE
Close Bandstand, back up your whole data folder, and extract the new ZIP
into a new folder. Run Start Bandstand there. It opens the same book.
The data folder is separate from the app; replacing the app does not reset it.
Keep the older app until you have checked your book with the new version.

TABLET ON YOUR WI-FI
Close Bandstand first, then open Share Bandstand on Wi-Fi. Both devices
must be on a trusted private network. On Windows, allow the packaged
runtime through the firewall for Private networks if you choose to share.
This launcher does not change your firewall or start a background service.
Open the printed tablet address in the tablet's browser. Get a sign-in
code from Settings on the computer. Keep director codes private; band
members can have their own read-only sign-in instead.
Wi-Fi HTTP is for connected reading. It does not enable offline storage
or installation on the tablet. For those, use your band's HTTPS server.

INSTALL THE WEB APP
On this computer, use Edge or Chrome's Install app option at the localhost
address. For a band's HTTPS address, use the browser's Install option;
on iPhone or iPad use Safari, Share, Add to Home Screen.
The icon opens the reader. Start Bandstand must still run when you need to
sync or fetch charts. Save charts offline before relying on them at a gig.

STOP
Close the Bandstand console window. Your book stays saved.
